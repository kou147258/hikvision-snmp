# v0.1.4 — Critical config-flow fix

This release fixes a bug that prevented the integration from being added
through the HA UI at all.

## Bug

When clicking **Add Integration → Hikvision SNMP**, HA showed:

```
无法加载配置向导: {"message":"Handler HikvisionSnmpConfigFlow doesn't support step basic"}
Handler HikvisionSnmpConfigFlow doesn't support step basic
```

The config flow's first step used `step_id="basic"` in `async_show_form`,
but the corresponding `async_step_basic` method was missing — only
`async_step_user` existed. HA resolves `step_id` → `async_step_<id>` by
convention, so when the user submitted the form, HA tried to call
`async_step_basic`, didn't find it, and surfaced the error.

## Fix

Added `async_step_basic` to `custom_components/hikvision_snmp/config_flow.py`.
`async_step_user` is kept as a thin entry-point that delegates to
`async_step_basic`, so both paths work:

```python
async def async_step_basic(self, user_input=None):
    if user_input is None:
        return self.async_show_form(
            step_id="basic", data_schema=USER_DATA_SCHEMA_BASIC
        )
    self._basic = user_input
    return await self.async_step_snmp()

async def async_step_user(self, user_input=None):
    """Entry point — delegates to the ``basic`` step."""
    return await self.async_step_basic(user_input)
```
