# v0.1.3 — Integration icon

This release adds a custom icon at `custom_components/hikvision_snmp/icon.png`
(512 × 512 PNG, ~250 KB). Home Assistant automatically picks up `icon.png`
placed alongside `manifest.json` and uses it in:

- **Settings → Devices & Services** integration card header
- **Device registry** device row icon
- **Sidebar** for integrations with sidebar entries (not used here, but
  applicable if added in the future)
- **HACS** repository card

## What's new

- **Integration icon** — `custom_components/hikvision_snmp/icon.png`, 512 × 512
  PNG. Source image was a 4000 × 2252 JPEG that was centre-square-cropped
  to 2252 × 2252 (avoiding the power pole in the bottom-right corner) and
  downscaled with Lanczos resampling to 512 × 512.

## No code changes

This release contains **no code changes** — it only adds the icon file.
All previous v0.1.2 behaviour is unchanged.

## Localization

`translations/en.json` and `translations/zh.json` continue to cover the full
config-flow, options-flow, error, and abort strings. Entity names remain
hard-coded English in `sensor.py` / `binary_sensor.py`; users on a Chinese
HA install can rename entities in the UI.
